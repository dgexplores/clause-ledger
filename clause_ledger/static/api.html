API reference

Browser ownership uses an HttpOnly, SameSite=Strict cookie. Keep cookies between calls. This demo does not authenticate real employees or provide legal advice.

Routes

GET /healthz — Runtime mode and storage status.

GET /api/samples — Three fictional source documents.

GET /api/documents — Reviews belonging to your session.

POST /api/documents — JSON: title, text, policy. Returns a new report and exact source ranges. Title: 1–120 characters; text: 30–50,000 characters.

POST /api/documents/pdf — Multipart: file, title, policy as JSON. Text PDFs only; 1 MiB, 10 pages, five-second parser deadline. Scanned and encrypted PDFs are rejected.

GET /api/documents/{id} — Source pages, findings and decision history. Other sessions receive 404.

POST /api/documents/{id}/review — JSON: reviewer, decision, note, expected_version. Decisions: approved, changes_requested, rejected. Stale versions receive 409.

DELETE /api/documents/{id} — Deletes the owned review and its history. Returns 204.

Policy

max_payment_days (default 60), max_breach_hours (72), min_uptime_percent (99.5), require_termination (true), require_audit (true). The report stores a snapshot of the policy used.

Errors and limits

422: invalid input or unsupported PDF. 404: missing or unowned review. 409: stale review version. 413: oversized request. 429: demo storage quota reached (20 reviews/session, 1,000 total). There is no LLM call, external action or email integration.
